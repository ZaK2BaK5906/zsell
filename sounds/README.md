# Sons pour Z-SELL

## police_alert.ogg

Placez ici un fichier son `police_alert.ogg` pour la notification de police.

### Où trouver un son gratuit :

1. **Freesound.org**
   - Recherchez "police radio" ou "alert beep"
   - Téléchargez en format .ogg ou convertissez avec Audacity

2. **Zapsplat.com**
   - Sons d'alerte gratuits
   - Exportez en .ogg

3. **Convertir un fichier**
   - Utilisez https://convertio.co/fr/mp3-ogg/
   - Ou Audacity (gratuit)

### Caractéristiques recommandées :
- Format : OGG Vorbis
- Durée : 1-3 secondes
- Volume : Normalisé
- Type : Alerte/beep/radio police

### Exemple de son :
Un beep court et aigu, ou un bruit de radio de police.

Une fois le fichier placé ici, il sera automatiquement chargé par le script.
